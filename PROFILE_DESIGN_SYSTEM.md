# CRYO Profile Design System

## Purpose

This repository presents a bilingual GitHub profile interface for **Pierreg99 / Cryopg.it**.

## Visual Language

- Dark, technical, minimal visual language.
- High information density without relying on JavaScript.
- Tables and aligned blocks create dashboard-like cards inside GitHub Markdown.
- Unicode symbols provide visual anchors without requiring image assets.
- DE/EN content is paired so both languages remain first-class.

## Information Architecture

1. Identity / Hero
2. Profile summary
3. Core domains
4. Featured project grid
5. Technology matrix
6. System architecture
7. Delivery pipeline
8. Navigation
9. Current direction
10. Footer / identity mark

## Design Rules

- Keep the hero compact and immediately scannable.
- Prefer paired DE/EN columns for equivalent content.
- Keep project descriptions short and link directly to GitHub repositories.
- Avoid unsupported JavaScript or client-side interaction.
- Use Markdown/HTML constructs that render reliably on GitHub.
- Keep the active profile in `README.md`; variants remain documentation/reference files.

## Active Variant

`README.md` = full CRYO profile interface.

## Alternative Variant

`README-PROFESSIONAL-PORTFOLIO.md` = professional portfolio presentation.
