# CRYO Profil-Designsystem

## Zweck

Dieses Verzeichnis enthält die deutsche Dokumentation des GitHub-Profil-Interfaces für **Pierreg99 / Cryopg.it**.

## Visuelle Sprache

- Dunkle, technische und minimalistische Bildsprache.
- Hohe Informationsdichte ohne clientseitiges JavaScript.
- Tabellen und strukturierte Blöcke erzeugen dashboardartige Karten innerhalb von GitHub Markdown.
- Unicode-Symbole dienen als visuelle Anker.
- Deutsche Inhalte sind vollständig eigenständig und werden nicht mit englischen Texten vermischt.

## Informationsarchitektur

1. Identität / Hero
2. Profilzusammenfassung
3. Kerndomänen
4. Projektübersicht
5. Technologiematrix
6. Systemarchitektur
7. Entwicklungsprozess
8. Navigation
9. Aktuelle Ausrichtung
10. Footer / Identitätsmarke

## Designregeln

- Hero kompakt und schnell erfassbar halten.
- Deutsche Dokumente enthalten nur deutschen Fließtext.
- Projektbeschreibungen kurz halten und direkt auf GitHub verlinken.
- Keine nicht unterstützte Client-Interaktion voraussetzen.
- GitHub-kompatibles Markdown/HTML verwenden.
- Sprachvarianten als getrennte Dateien organisieren.
