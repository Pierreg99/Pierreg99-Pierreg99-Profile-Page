# CRYO Profile Design System

## Purpose

This directory contains the English documentation for the GitHub profile interface of **Pierreg99 / Cryopg.it**.

## Visual Language

- Dark, technical, minimal visual language.
- High information density without client-side JavaScript.
- Tables and structured blocks create dashboard-like cards inside GitHub Markdown.
- Unicode symbols act as visual anchors.
- English content is fully standalone and is not mixed with German prose.

## Information Architecture

1. Identity / Hero
2. Profile summary
3. Core domains
4. Featured projects
5. Technology matrix
6. System architecture
7. Delivery pipeline
8. Navigation
9. Current direction
10. Footer / identity mark

## Design Rules

- Keep the hero compact and immediately scannable.
- English documents contain English prose only.
- Keep project descriptions short and link directly to GitHub repositories.
- Do not depend on unsupported client-side interaction.
- Use GitHub-compatible Markdown/HTML.
- Store language variants as separate files.

## Active English Presentation

`docs/en/PROFILE-EN.md` is the standalone English profile view.
