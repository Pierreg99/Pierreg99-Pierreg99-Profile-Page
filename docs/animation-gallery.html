Integrity rules

  • Animations remain local, tracked files.
  • No remote runtime dependency is required to render them.
  • Markdown and HTML references are validated by scripts/validate-local-links.py in CI.
  • Animation filenames are canonical; presentation surfaces should reference these files rather than duplicate assets.
  • The animation layer is presentation evidence only and is not independent proof of a technical capability.
