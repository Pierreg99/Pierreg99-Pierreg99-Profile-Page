## Method boundary

The reports use GitHub repository evidence plus external research. They are portfolio/artifact benchmarks, not psychometric IQ tests and not individual personnel ratings.

DORA delivery metrics are treated as service/team process measures rather than individual performance scores. Academic learning evidence is used for methodology, not for claiming a person's measured intelligence.
