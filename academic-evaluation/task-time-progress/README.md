# Task Duration & Calendar

Bilingual operational planning set for task duration, calendar scheduling and progress tracking.

Files:
- `Task_Duration_Progress_DE_EN.csv` — task times, planned/actual duration, status and progress.
- `Academic_Productivity_Task_Calendar_DE.ics` — German calendar events.
- `Academic_Productivity_Task_Calendar_EN.ics` — English calendar events.
- `TASK_TIME_PROGRESS_DE.md` — German documentation.
- `TASK_TIME_PROGRESS_EN.md` — English documentation.
- `Task_Duration_Calendar_DE_EN.zip` — packaged operational set.
