# Evidence Boundary

The visual system deliberately separates **verified core portfolio language evidence** from contextual ecosystem notation. The current public core-language evidence is Python, TypeScript and JavaScript. Extended symbols such as HTML, CSS, SQL, YAML, JSON, Shell and Markdown are presentation vocabulary unless independently verified in repository manifests.

The score graphics are portfolio/evidence signals, not formal certification or personnel assessment.

## Design Contract

**CRYO visual grammar:** dark HUD surfaces, thin technical borders, vector-first geometry, semantic SVG metadata, evidence-aware labels, bilingual navigation, and a deliberate separation between identity, technology, evidence and delivery.
