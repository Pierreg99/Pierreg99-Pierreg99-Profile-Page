The covers were edited with OpenAI image generation using local project images as references. They are portfolio presentation artwork, labeled **Portfolio cover** on the website. They represent each project's visual identity and are not unedited gameplay or interface captures. The explorer and gallery use the original [project previews](../projects/README.md), whose source links and capture dates remain available.

Canonical covers are 1440 × 810 JPGs. The build generates 480, 960, and 1440 pixel WebP variants. [The manifest](manifest.json) records the reference image, original source, dimensions, editing date, and checksums for each cover. Attribution for the reference imagery remains with its source project.
