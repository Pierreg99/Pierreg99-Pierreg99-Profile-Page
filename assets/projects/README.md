Resident Lovely uses its Sweet Château repository artwork. KiBlox, Cryoplane, Cyberdash, and Call of Groky use screenshots supplied by their repositories. cryOS was captured in CryArch desktop mode with Files and Settings open. CryAIPulse, AI for Everyone, Command Wiki, Cryo Progress, and this portfolio were captured from their public websites. CRYOGAMEHELP uses its repository's universal hub illustration.

Call of Shooty was captured from the repository served locally; a public demo was not available when reviewed. CRYOGAMEHELP also has no verified public demo. Their portfolio actions lead to source repositories. Streamflixrouge uses the upstream Streamflix Reborn preview supplied in its README, with the original project's attribution preserved.

Images are resized and compressed for delivery without changing their visual content. The build produces 480, 960, and 1440 pixel WebP variants. [The manifest](manifest.json) records each source, image kind, dimensions, review date, and checksum. Screenshots represent the review date, rather than continuously updated project status. Rights and attribution remain with the respective source projects.
