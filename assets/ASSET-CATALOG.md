## Design standard

All original vectors use accessible titles/descriptions, scalable dimensions, and a shared CRYO visual language. External brand logos are represented only where appropriate; the original symbol sheets are custom presentation graphics.

## Evidence standard

Core language evidence is kept separate from contextual ecosystem symbols. Visual design must not imply verified use of a technology without repository evidence.
